# PCEP Training Material

A practical study guide for the Python Institute PCEP-30-02 exam. Use the official [PCEP exam syllabus](https://pythoninstitute.org/pcep-exam-syllabus) as the source for exam objectives.

## How to use this file

Work through one topic at a time. Type and run short examples, explain what you expect before running them, and revisit any topic you cannot explain. Use [PCEP ChatGPT Instructions](PCEP_ChatGPT_instructions.md) for guided lessons and [PCEP Mock Exam](PCEP_30-02_Mock_exam.md) for exam practice. The mock answer key is at the end; attempt questions before checking it.

## 🧭 Course Map

| Block | Official weight | Focus |
|---|---:|---|
| 1. Computer programming and Python fundamentals | 18% | Python basics, literals, variables, operators, input/output, types, errors |
| 2. Control flow | 29% | Conditions, loops, ranges, branching and loop control |
| 3. Data collections | 25% | Strings, lists, tuples and dictionaries |
| 4. Functions and exceptions | 28% | Defining and calling functions, parameters, scope, exceptions and modules |

## 🧱 Block 1 — Programming and Python Fundamentals

- Understand source code, interpreters, compilation, and how Python runs a program.
- Use valid identifiers, keywords, comments, indentation, and basic syntax.
- Work with integers, floats, strings, booleans, and `None`; inspect values with `type()`.
- Assign values and use arithmetic, comparison, logical, and basic bitwise operators.
- Read input with `input()` and display results with `print()`; convert input when needed.
- Recognize syntax errors, runtime exceptions, and logical errors.

## 🔀 Block 2 — Control Flow

- Use `if`, `elif`, and `else` with comparisons and Boolean expressions.
- Build `while` and `for` loops; use `range()` to control iteration.
- Apply `break`, `continue`, and `pass`; understand loop `else` clauses.
- Trace nested conditions and loops carefully, keeping track of each variable's value.

## 🧺 Block 3 — Data Collections

- Create strings and use indexing, slicing, concatenation, membership, and common methods. Strings are immutable.
- Create lists; index, slice, update, append, remove, and iterate over elements.
- Use tuples for ordered, immutable collections and unpack tuple values.
- Create dictionaries and access, add, update, and remove key/value pairs.
- Choose the collection that fits the task and distinguish mutability from ordering.

## 🛠️ Block 4 — Functions and Exceptions

- Define functions with `def`; call them and return results with `return`.
- Distinguish parameters from arguments; use positional, keyword, and default arguments.
- Understand local and global names, and recognize function scope.
- Handle expected errors with `try` and `except`; understand `else` and `finally`.
- Import modules with `import` and `from ... import`; use aliases and recognize packages.

## ✅ Practice Routine

1. Study a small topic and type a working example.
2. Predict the output before running code.
3. Explain the result in your own words.
4. Attempt related mock questions without opening the answer key.
5. Review mistakes, then retry with a fresh example.
